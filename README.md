SMART ATTENDANCE SYSTEM :

A Java desktop application that automates classroom attendance using webcam-based facial recognition.



#FEATURES :-

-Admin login

-Student registration

-Webcam-based face dataset capture

-OpenCV face detection

-Automatic attendance marking

-Duplicate attendance prevention for the same date

-Today's attendance dashboard

-Attendance percentage



#REQUIREMENTS :-

JDK 17 or newer

Maven 3.8+

Working webcam

Windows/Linux/macOS
